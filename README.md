# Local Service Finder

A responsive website prototype for discovering local service categories and sample provider listings.

## Features
- Mobile-friendly layout
- Browse service categories
- Search listings and filter by category
- Enquiry form that opens the visitor's email application
- Built with plain HTML, CSS and JavaScript

## Run locally
Open `index.html` in a web browser.

## Publish
This repository includes a GitHub Pages deployment workflow. Open the repository's **Actions** tab and check the Pages workflow. After its first successful deployment, the website should be available at:

https://meghakursange25-cpu.github.io/local-service-finder/

If GitHub asks you to enable Pages, open **Settings → Pages** and set **Source** to **GitHub Actions**.

## Important demo limitations
The provider listings are sample data, not verified businesses. Replace them with real provider details before public use. This static prototype has no database, user accounts, live location lookup, or real booking system. The enquiry form prepares an email; it does not send or store enquiries itself.
